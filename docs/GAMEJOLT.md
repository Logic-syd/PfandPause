# Game Jolt 发布说明

当前测试版为二十关、不限时的七格传送带三瓶配对：露出的瓶子可以点，三个同款自动退走，七格满槽失败。没有撤销、移出或洗牌道具。主堆采用多种错层形状，两侧有长叠堆；第 11 关开始混入玻璃分类，三次投错结束本轮。中英德同步。当前先测试，不生成新 ZIP。

代码和 GitHub Pages 更新不会自动更新 Game Jolt。准备上传时，在 [Packages 后台](https://gamejolt.com/dashboard/games/1106213/packages) 编辑或新增 Release，将包含根目录 index.html 与 assets/ 的 ZIP 上传到 **Upload Browser Build**。

HTML 构建的 Fit to screen 可开启，HTTPS support 保持开启；游戏按实际嵌入窗口适配。未开启 Fit to screen 时，需要填写 Width / Height 并保存，直到 Incomplete 消失。发布 Release 后还需确保游戏页面本身已发布。公开游戏链接为 https://gamejolt.com/games/pfand-pause/1106213 。

测试网站为 https://logic-syd.github.io/PfandPause/ 。本地回归使用 Chromium 模拟嵌套框、触控及各种窗口；真实 Safari 和 Game Jolt 仍需设备测试。

以下为旧版发布与排查记录，涉及倒计时、扣秒、撤销、三格储存／两个接收位／滑动的说明均不适用于当前玩法。

## 历史更新（限时接收队列版本，已停用）

- 撤销优先收回储存区最后一瓶，回到原列；储存区空时可撤尚未凑齐的接收瓶或玻璃选择。已凑齐并退回的三瓶不再回来，接收队列、扣时和错误次数不回退。第九关截图中的局面可撤一次，再连续点击第二列三次，打开气泡水接收位。

- 第六至第十关限时为 42／40／38／35／32 秒，逐步增加速度压力；前五关与玻璃关卡时间保持不变。最后 10 秒以大号数字逐秒倒数，开启声音时有短促提示音；帮助暂停、静音和减少动画设置仍有效。

- 首页介绍改为日常、轻松的语气：不同瓶子对应不同押金，不能退的玻璃瓶进入对应颜色的回收桶。中英德同步调整，去掉金额列举和预告式说明。

- 撤销放在棋盘上方右侧，重开在左侧；中间的储存区提示始终显示。点错时在计时区域短暂弹出醒目的 −5 秒／−10 秒，连续错误重新显示，不影响棋盘位置或缩放。

- 关卡地图去掉课程式说明，关名采用轻松的游戏主题；十五关各有一句通关鼓励，中英德同步。

- 顶部直接显示中文／EN／DE，一次点击切换并保存语言；设置里只保留声音和减少动画。
- 第五关开局接收位调整为黑加仑与柠檬，重新验证接收队列与完整通关路径。

- 恢复完整首页的店铺插画、介绍与进度，主要入口同屏显示；点开始直接进入关卡，不强制教学。
- 教学全步骤适配弹窗，确认／撤销按钮留在缩放区外；完成后收起空棋盘，只显示总结。
- 回收练习压缩标题和包装卡，答题前六个选项完整显示，答题后替换为正确去向与解释；下一题按钮保持可见。参考说明独立查看。
- 主线改为限时退瓶机：前十关使用 0.25／0.15／0.08 欧元示例押金，11–15 关逐步加入白／棕／绿无押金玻璃，需要点选后投到对应回收箱。
- 暂存位满后继续取不匹配瓶子扣 5 秒；玻璃投错扣 10 秒；三次投错或倒计时结束后本轮结束。撤销不返还惩罚；帮助和离开棋盘暂停。
- 通关统计改为本关归还瓶数与模拟押金，并单独显示无押金玻璃回收数。瓶子标有明确示例金额，以整数分累计，不据饮料或颜色推断真实押金。
- `test:practice-fit` 验证三语、6种窗口、教学每一步、八个问题的作答／反馈、总结及 12 瓶 / €2.40 的通关统计，均无内容滚动；实体手机仍需用户测试。

`test:timer` 验证实际倒计时、帮助暂停、两种扣时、惩罚无法通过撤销清除、超时／三次投错及重开。`test:glass` 检查三语和短窗口下全部五个玻璃关卡、投错提示、撤销、无押金统计和刷新存档。

投错结束提示按用户要求简化为实际投错次数，以及“友情提醒：现实中投错可能会被处罚。”中英德同步，不显示罚款金额或具体法律条文。

## 1.0.3

- 打开即进入首个未完成关卡，取消大标题、启动页和强制新手教程；帮助、练习及回收知识仍从顶部一行操作栏进入。
- 正式棋盘按实际 iframe 的宽高缩放，瓶子、暂存区和两个箱子一起显示，无需上下滚动。矮宽窗口采用并排布局，避免把瓶子缩得过小。
- 撤销、重开和队列按钮保留在缩放区之外，至少 44px 高；首屏顶部为 48px。瓶子的可点击区随画面一起适配，飞行动画也按瓶子实际尺寸调整。
- 所有页面和弹窗隐藏滚动条；长订单和教学弹窗仍可独立滑动。手机使用动态窗口高度与底部安全区，避免浏览器工具栏遮住底部操作。

`test:fit-board` 在双层无文档滚动的嵌入框中检查 240×320、320×320、320×568、390×568、390×844、844×390、1280×431、1280×720、1920×320、2560×1440 和 3840×2160 的全部十关：无棋盘溢出、内容完整显示、无滚动条，并检查点击／撤销。其他回归覆盖不同像素密度、动画时调整窗口、鼠标／触控、三语、全部十关通关、订单弹窗、练习和音效异常。上述为 Chromium 模拟检查，真实 iPhone Safari 仍需在设备上复测。

## 1.0.2

- 针对移动浏览器在平台多层 iframe 中不能执行原生滑动的情况，增加游戏内部的纵向触摸拖动和惯性滚动。
- 手指从瓶子上开始滑动时滚动页面，松手不会误选瓶子；下一次正常点击仍可操作。
- 弹窗优先滚动自己的内容，避免带动后面的棋盘；两指手势交给浏览器处理。直接打开游戏时继续使用原生滚动。
- 游戏窗口尺寸仍由平台的 Fit to screen 设置决定，没有加入固定画面宽高或缩放比例。

新增检查在跨源双层 `scrolling="no"` iframe 中禁用浏览器原生触摸平移：`1.0.1` 无法滚动，`1.0.2` 验证瓶子上的上下滑动、点击和撤销、独立弹窗滚动及两指事件处理。另验证直接打开时的原生滑动。测试使用 Chromium；当前环境无法下载 WebKit，尚未验证真实 iPhone Safari，需在原设备上复测。

## 1.0.1

- 游戏使用独立的纵向滚动容器，处理平台双层 iframe 的 `scrolling="no"` 限制；已通过 Chromium 嵌入测试。移动浏览器仍可能需要 1.0.2 的触摸兼容处理。
- 手机竖屏压缩棋盘空白，扩大瓶子、帮助、撤销和重开的触控区域，保留安全区边距。订单由棋盘上方的队列按钮查看，手机不再重复显示侧栏。
- 矮屏上固定操作栏；弹窗退出时避免跳到原按钮位置。导航和重开重置游戏滚动位置。
- 教学练习中暂时不可选的瓶子会变淡。
- 音效设备异常不再中断操作、使瓶子按钮永久锁定。

测试覆盖 Chromium 的触控／鼠标模拟、320×568、390×844、844×390、1280×720 @2、1707×960 @1.5、2560×1440、3840×2160；也检查动画中改变窗口大小、三语、嵌入框内滚动和音效异常。没有据此断言已经复现朋友的具体 2K 故障，需要在原浏览器与缩放设置下复测。
